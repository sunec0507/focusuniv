# Timetable bulk input (future)

Not implemented. Screenshot OCR is out of scope for the current release.

Intended order, if this is built later:

1. Text or CSV paste for one-shot import.
2. Sequential entry of several courses in one form.
3. Screenshot OCR as an assist, not a silent importer.
4. A review screen that shows every recognized course, time, and room.
5. Save only after the user confirms.

OCR output must never be written to the timetable automatically. The user always reviews and accepts the rows first.
